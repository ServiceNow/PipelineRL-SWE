# Calibration-selected fixed-policy evaluation

Per dataset, choose V by maximizing OUR router's mean expected validation utility `V * q - observed_mean_generation_cost`, where q is expected valid-draw correctness, only on original calibration problems. Freeze V. On original untouched test IDs, use the learned success/cost predictions to choose one route/problem; no convex-hull mixtures. Compare OUR learned cost to median training-output cost with identical OUR success probabilities and selected V. Report test accuracy, mean observed generation spend, paired absolute cost difference, paired percentage savings, and paired accuracy difference. Bootstrap problems, 2,000 draws seed20261001, all route/draw labels stay grouped. The selected V was at the top of the frozen grid (100 cents, or $1, per expected correct answer) for all three historical calibration sets; treat this as a boundary selection, not a well-identified operating preference.

This is an evaluation-policy demonstration, not fresh independent evidence: original test outcomes have been explored. Do not use these values as the paper's new confirmatory result. Once expansion collection completes, score the frozen policy/models on fresh expanded IDs and report that sample separately. Fixed policy and frontier summaries answer different questions; neither should silently replace the other.
